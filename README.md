# Parcial Microservicios

Proyecto de práctica enfocado en arquitectura de microservicios, con servicios desacoplados y bases de datos independientes por dominio.

## Estructura
- `database1` / `database2` — bases de datos independientes por servicio
- `fastapi_project` — API construida con FastAPI (Python)
- `serverless` — funciones serverless

## Objetivo
Explorar el diseño de sistemas distribuidos: separación de responsabilidades, comunicación entre servicios y despliegue independiente por componente.
